# Mix

Mute, solo, gain, phase, Delay / Pre, and Send live here. Duck is how the stick punches a hole in the shell so you can actually hear the click.

- **Duck / Time** — dips Shell when Stick hits. 0 is off. Wires, Stick, and Sample stay put, which is the point.
- **Per-layer faders** — mute, solo, phase, and **Send** (how much of that layer goes into the FX send).

Stereo **Output** is always the full mix, so a host that ignores extra pins still hears the whole drum.

Optional extra stereo buses **Snare**, **Slot 1**, **Slot 2**, **Slot 3** are that mix layer after mute/solo/gain, before Width and post FX. Leave them off if you do not need stems.
