# Patches

**Init Patch** in the title bar shows a factory preset as Category / Name. Click for Init / Save / Save As / Export / Import, a factory category, or your saved list. Chevrons step the factory bank, then any extra patches.

Your files live in `%AppData%\Stupid Audio\SNR3\Patches` as `.snr3p`. Saving a factory name stores your copy there; delete that file to hear the factory sound again.

Click **SNR3** plus the version in the top left for About and a GitHub update check.

Drag the window corner to scale (40%–150%). The scale is saved with the session, so you do not have to re-negotiate with the pixels every time.
