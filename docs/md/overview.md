# Hello, snare

SNR3 is a snare one-shot. The default is 909-ish: short stick, mid wires, short shell. Classic, Fat, Snap, Tight, and Hard are personalities, not a tour of vintage drum machines.

MIDI note-on retriggers and sets Shell pitch from the note (A4 = 440 Hz). The Tune knob is for Standalone Play, the waveform, and WAV export — so the knob and the MIDI note are not fighting each other.

This is the user book. Internals live under Spec, Architecture, and DSP notes in the sidebar, if you enjoy reading the wiring.

VST3 and standalone. Windows, Linux, and Mac.
